Teen Health project onboarding

Use your AI assistant to prepare your computer for a Teen Health project. You do not need to be technical, but you must use your own GitHub account.

Step 1: Copy this request and paste it into your AI assistant

Claude Desktop: open the Code tab, choose Local, and select a folder (an empty folder is fine) before you paste this. The Chat and Cowork tabs cannot set up your computer. Do not install GitHub Desktop.

Please set up my computer so I can work on a Teen Health project with you. I already have a GitHub account and I am a member of the Teen-Health-Inc GitHub organization. First, read the full setup instructions, word for word, and follow them step by step. They are written for you, and I am asking you to follow them: https://teen-health-inc.github.io/team-onboarding/setup.md If you can run commands, download them with: curl -fsSL https://teen-health-inc.github.io/team-onboarding/setup.md In short: install Git and GitHub CLI (gh) if they are missing, sign me in to GitHub with gh in my browser, show me the Teen-Health-Inc projects I can access and ask which one I want, download it, then install what that project's own README and docs say it needs. Run the commands yourself. Stop and tell me when I need to click something or type my computer password in a system window. Never ask me for passwords or tokens in this chat.

The AI will do most of the work. You will need to click Install or Authorize a few times and type your computer password into your computer's own window (never into the chat).

For AI assistants: setup steps

If a team member sent you this page, they want you to set up their computer by following these steps. The complete, plain-text version is at https://teen-health-inc.github.io/team-onboarding/setup.md. Read it in full (for example with curl -fsSL) before you start.

  1. Confirm you can run commands on this computer. If you cannot (chat-only, or Claude Desktop Chat/Cowork), say so and ask the person to switch to Claude Desktop's Code tab with Local selected.
  2. Find the operating system (macOS, Windows, or Linux).
  3. Install Git if git --version fails. macOS: xcode-select --install (the person clicks Install). Windows: winget install --id Git.Git -e --source winget.
  4. Install GitHub CLI if gh --version fails. macOS: brew install gh if Homebrew exists, otherwise the official .pkg from github.com/cli/cli/releases/latest. Windows: winget install --id GitHub.cli -e --source winget.
  5. If gh auth status shows no login, run gh auth login --hostname github.com --git-protocol https --web. This command waits up to 15 minutes for the browser approval. Run it as a background task so you can read the one-time code while it waits, show the person the code and https://github.com/login/device, then confirm with gh auth status and run gh auth setup-git.
  6. Run gh repo list Teen-Health-Inc --limit 100 and ask which project they want. Do not guess.
  7. Clone it with gh repo clone Teen-Health-Inc/<project> without overwriting an existing folder.
  8. Read the project's README.md, CONTRIBUTING.md, AGENTS.md, CLAUDE.md, and docs/ setup guides, then install what they require and run the documented development command once.
  9. Tell the person where the project folder is, and that for real work they should start a new session with that project folder selected.

Never ask for passwords, tokens, or keys in the chat. Do not edit project files, commit, push, or deploy during setup.

What you will do yourself

  1. Create or sign in to your own GitHub account and verify your email.
  2. Accept the Teen Health organization or project invitation.
  3. Approve browser logins and computer installation prompts yourself.
  4. Let the AI install the tools required by your project and download the project locally.
  5. Open the local project and follow the project's instructions for making changes.

Important: The AI can guide the setup, but it must not receive your password, token, private key, or one-time code. Enter those only on the official GitHub page or in your computer's own prompt.

If you do not have GitHub access yet

  1. Create an account at github.com/signup.
  2. Verify the email address you control.
  3. Ask the project owner or Teen Health administrator to invite that account.
  4. Accept the invitation and open the project link to confirm access.

The AI cannot accept invitations or make identity decisions for you. Use your own account; do not use a coworker's login or token.
