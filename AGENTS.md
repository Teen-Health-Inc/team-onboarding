# Onboarding repository instructions

This repository is a public, documentation-only onboarding hub for all Teen Health project teams.

Before changing anything, read:

1. `README.md`
2. `docs/account-access.md`
3. `docs/ai-setup.md`
4. `docs/project-workflow.md`

Keep the documentation vendor-neutral so it works with Codex, Claude, Cursor, Gemini, GitHub Copilot, or another AI assistant.

Do not request, store, or expose passwords, GitHub tokens, private keys, one-time login codes, production credentials, VPS details, or `.env` values.

This repository is not a project source repository. The target project must be supplied by the user or an approved project owner. Do not guess a project, clone or modify project source, or publish project changes from here.

Keep changes focused, use plain language, and make sure instructions are safe for nontechnical team members. Human review is required before publishing changes to this public repository.
